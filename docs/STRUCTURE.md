# NAC v3.3.16 — repository structure

This package is organized for direct upload to the root of the NAC-1 repository.

- `frontend/` — Next.js web application
- `backend/` — FastAPI application and tests
- `database/` — SQL schema
- `docs/` — documentation
- `.github/workflows/` — CI
- root — Docker Compose and project metadata

Upload the **contents of this folder** to the root of the GitHub repository, not the parent folder itself.
